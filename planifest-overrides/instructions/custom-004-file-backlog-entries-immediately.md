### File Backlog Entries Immediately
If you find an out-of-scope problem, file it as a backlog entry straight away. Don't ask first, and don't offer to file it later. Follow `planifest-framework/templates/backlog-entry.template.md`, then commit the entry and push it to the current feature branch.

This holds at every phase, including P7 to P9. While the feature branch or its PR is still open, the entry ships with that PR. Report the entry ID in your reply so the human on the loop can see it.

**Why:** In 0000033, a P9 defect became backlog 0000124 only after the human on the loop said yes. By then they had merged PR #59, so the entry missed the merge and sat on a stale branch.
