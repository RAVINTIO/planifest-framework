## Findings (severity-ordered)

- [major] `execution-plan.md` NFR-003, `risk-register.md` R-010, and `adr/ADR-001-stack-unchanged-node-built-ins-no-spawn.md`: NFR-003 requires no `child_process` import and no non-`node:` import "in any enforcement hook". R-010 says a suite scans "the hooks". `ratchet-check.mjs:53` imports `node:child_process` and calls `execFileSync("git", ...)` at `:150`. Every hook imports a local module such as `./read-stdin.mjs`. A suite built from that text fails, and a fix loop could remove the `git` spawn, which changes ratchet behaviour outside scope. Reword NFR-003 and R-010 to match ADR-001: `path-rules.mjs` and `em-dash-guard.mjs` import no `node:child_process`, and no hook imports anything outside `node:` or `./`. ADR-001 should also name the existing `ratchet-check.mjs` spawn and backlog 0000128, as 0000035 ADR 001 does. Its positive consequence "with no process start" should exclude `ratchet-check.mjs`.
- [major] `adr/ADR-005-drift-check-warn-only-node-script.md` and `execution-plan.md` A-001: the ADR claims "A correct install reports no drift, whether setup ran from `setup.sh` or `setup.ps1`." `setup.ps1:175` reads each `SKILL.md` with `Get-Content -Raw` and no `-Encoding`, then writes it with `-Encoding UTF8` at `:180`. Windows PowerShell 5.1 reads a file with no byte order mark in the ANSI code page. Ten source skills hold non-ASCII text, among them the design critic, loop runner, and migrator. On PowerShell 5 those copies install as double-encoded text, and the drift check reports them stale after every setup run. `planifest-refresh-setup` can't clear the warning. Correct the positive consequence, A-001, and R-012 to name this case. The fix is in `setup.ps1`, which `scope.md` puts out of scope, so the orchestrator should file a backlog entry for the missing `-Encoding UTF8` at `setup.ps1:175`.
- [minor] `adr/ADR-002-non-regular-design-md-reads-as-no-design.md` and `requirements/req-008-non-regular-design-md.md`: the kept fail-open line lets an agent open the gate with no race. It can run `chmod 000 plan/current/design.md`, and then the guarded open throws `EACCES` and the write passes. The design confirms this line, so it isn't a defect in this feature. ADR-002 lists the microsecond `ELOOP` race as a risk but not this simpler route. Name it under Risks. The orchestrator should file a backlog entry, because no entry tracks it today.
- [minor] `adr/ADR-004-shown-cuts-whole-units-shared-by-hooks.md` Consequences: "A partial install that copies only `em-dash-guard.mjs` would then exit 0 on every call." A missing static ESM import makes Node exit 1, not 0, before any `try` runs. Claude Code treats exit 1 as a non-blocking error, so the guard still does nothing. State exit 1 and that effect.
