### What Was Built

Version 0.37.0 renames the framework to RAVINTIO. It is a minor bump, not 1.0.0, and it folds in backlog 0000237 with ten requirements. One scripted pass did the bulk rename.

- **Pack paths and identifiers (req-001):** the pack folder is `ravintio-framework/`, the overrides folder is `ravintio-overrides/`, the 21 skills are `ravintio-*`, and the workflow is `ravintio.yml`.
- **Runtime names (req-002):** the markers are `.ravintio-session`, `.ravintio-manifest`, and `.ravintio-setup-flags`. Setup stops while the old pack exists and replaces old block markers.
- **Environment variables (req-003):** `RAVINTIO_*` replaces the old prefix. The OpenCode adapter still reads the old session ID variable when the new one is unset.
- **Brand prose (req-004):** docs, skills, templates, and links say RAVINTIO.
- **History protection (req-005):** archives, changelogs, and shipped migrations stay byte-identical.
- **Consumer migration (req-006, req-009):** `migrate-0.37.0-ravintio-rename.md` with `.sh` and `.ps1` helpers. The helpers back up and never delete. The migrator maps old paths and honours `Applies when:`.
- **Brand guard (req-007):** a suite fails on any old-brand hit in a tracked path or line, with an allowlist of 26 entries.
- **Emitted names (req-008):** hook and setup messages start with `[RAVINTIO]`.
- **Version bump (req-010):** `product.yml`, the pack manifest, and `docs/about.md` read 0.37.0.

P5 rated the feature Low after three Medium findings were fixed and re-reviewed as closed.

### Upgrade steps for a consumer

1. Copy the new `ravintio-framework/` folder into the project root.
2. From the project root, run the helper:
   - Bash: `bash ravintio-framework/migrations/migrate-0.37.0-ravintio-rename.sh`
   - PowerShell: `pwsh -File ravintio-framework/migrations/migrate-0.37.0-ravintio-rename.ps1`
3. Run `ravintio-framework/setup.sh` or `setup.ps1` for each tool the project uses, before the next commit.
4. Check `.ravintio-backup/planifest-framework/` for custom files. Then delete `.ravintio-backup/` yourself.
5. Search your override files for old pack paths with `grep -rn 'planifest-framework/' ravintio-overrides/`. The helper does not rewrite them.

Setup refuses to run while the old pack or old overrides folder exists, so step 2 is required.
