- **Runtime names (req-002):** the markers are `.ravintio-session`, `.ravintio-manifest`, and `.ravintio-setup-flags`. Setup stops while the old pack exists and replaces old block markers. Setup reads neither `.planifest-setup-flags` nor `.planifest-manifest`. ### Upgrade steps for a consumer

1. Copy the new `ravintio-framework/` folder into the project root.
2. From the project root, run the helper:
   - Bash: `bash ravintio-framework/migrations/migrate-0.37.0-ravintio-rename.sh`
   - PowerShell: `pwsh -File ravintio-framework/migrations/migrate-0.37.0-ravintio-rename.ps1`
3. Run `ravintio-framework/setup.sh` or `setup.ps1` for each tool the project uses, before the next commit. Use the command the helper prints, because it carries the flags from each saved flags file.
4. Check `.ravintio-backup/planifest-framework/` for custom files. Then delete `.ravintio-backup/` yourself.
5. Search your override files for old pack paths with `grep -rn 'planifest-framework/' ravintio-overrides/`. The helper does not rewrite them.

Setup refuses to run while the old pack, the old overrides folder, or an old setup marker file exists, so step 2 is required.
